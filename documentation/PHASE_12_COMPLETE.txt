## 🚀 QUICK INTEGRATION

### Step 1: Wrap App
```typescript
import { I18nProvider } from './contexts';

<I18nProvider>
  <App />
</I18nProvider>
```

### Step 2: Add Switcher
```typescript
import { LanguageSwitcher } from './components/common';

<header>
  <LanguageSwitcher variant="dropdown" />
</header>
```

### Step 3: Use Translations
```typescript
import { useI18n } from './hooks';

const { t } = useI18n('auth');
<h1>{t('login.title')}</h1>
```

That's it! 🎉
