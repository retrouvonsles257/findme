## ✨ What Each Error Page Does

### 404 Not Found
- Shows "Page not found" message
- Suggests checking the URL
- Provides "Go back" and "Home" buttons
- Includes support contact link

### 401 Unauthorized  
- Shows "Authentication required" message
- Lists possible reasons (session expired, invalid credentials, etc.)
- Provides login button
- Includes help center link

### 403 Forbidden
- Shows "Access denied" message
- Displays user's current role and organization
- Explains insufficient permissions
- Provides "Request access" option

### 500 Server Error
- Shows "Server error" message
- Displays service status and request ID
- Explains what's being done to fix it
- Provides retry button (max 3 times)
- Includes report issue button
